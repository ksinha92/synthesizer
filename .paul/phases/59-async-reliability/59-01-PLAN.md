# Phase 59 Plan 01 — DLQ + celery_task_id + JobType Enum

## F8 — DLQ populated via task_failure signal

**Files:** `backend/app/infrastructure/messaging/celery_app.py`, each `*_tasks.py`

Add at top of `celery_app.py`:
```python
from celery.signals import task_failure

@task_failure.connect
def handle_task_failure(sender=None, task_id=None, exception=None, args=None, kwargs=None, einfo=None, **_):
    """Insert DeadLetterJobModel when retries exhausted."""
    request = sender.request if sender else None
    if not request or request.retries < (sender.max_retries or 0):
        return  # not exhausted yet
    job_id = kwargs.get("job_id") or (args[0] if args else None)
    if not job_id:
        return
    # Open a sync session here (Celery worker context) — use existing sync_session helper or run async via run_until_complete
    from app.infrastructure.persistence.database import sync_session
    from app.infrastructure.persistence.models.job import DeadLetterJobModel
    from sqlalchemy.dialects.postgresql import insert
    with sync_session() as s:
        stmt = insert(DeadLetterJobModel).values(
            id=uuid.uuid4(),
            original_job_id=uuid.UUID(str(job_id)),
            job_type=sender.name.split('.')[-1],
            payload={"args": list(args or []), "kwargs": dict(kwargs or {}), "exception": str(exception)},
            retry_count=request.retries,
            failed_at=datetime.now(timezone.utc),
        ).on_conflict_do_nothing(index_elements=["original_job_id"])
        s.execute(stmt)
        s.commit()
```

Each worker also writes `connection_id` into the payload via task kwargs (or via the existing task signature) so admin retry has what it needs.

Add a partial unique index on `dead_letter_jobs.original_job_id` if not present — migration 024.

## F9 — celery_task_id stamping

**Files:** `discovery_tasks.py`, `masking_tasks.py`, `synthetic_tasks.py`, `subsetting_tasks.py`, `compliance_tasks.py` (already stamps), `workflow_tasks.py`

At the top of every `_run_*_async` (or before first DB write in the sync task entrypoint), add:
```python
async with get_session() as session:
    job = await session.get(JobModel, uuid.UUID(job_id))
    if job and not job.celery_task_id:
        job.celery_task_id = self.request.id
        await session.commit()
```

Compliance already does this — confirmed in Phase 57.
