# Phase 59 Plan 02 — Workflow Reliability

**File:** `backend/app/infrastructure/messaging/workflow_tasks.py`

## Changes

### Checkpoint resume
At top of `_run_async`:
```python
last_completed = job.checkpoint.get("current_node") if job.checkpoint else None
last_step = job.checkpoint.get("step", -1) if job.checkpoint else -1
start_index = last_step + 1 if last_completed else 0
```
Loop iterates `for i, node in enumerate(order[start_index:], start=start_index):` and writes `checkpoint = {"current_node": node.id, "step": i}` after each node completes.

### NODE_TIMEOUT enforcement
Wrap each `_execute_node` call:
```python
try:
    await asyncio.wait_for(_execute_node(node, ...), timeout=NODE_TIMEOUT)
except asyncio.TimeoutError:
    raise NodeTimeoutError(f"node {node.id} exceeded {NODE_TIMEOUT}s")
```

### Fail-fast on unknown node types
At the `else` branch of node-type dispatch (currently silent `pass`):
```python
else:
    raise ValueError(f"Unknown workflow node type: {node.type}")
```

### `quality_check` removal
- Remove handling for `quality_check` in `workflow_tasks.py`.
- Remove from `WorkflowValidator.VALID_NODE_TYPES` in `domain/workflow/services.py`.
- Remove from palette in `frontend/src/components/workflows/node-palette.tsx`.
- Migration not required — existing workflows that reference `quality_check` will fail validation on next execute (acceptable; flag in release notes).

### TOCTOU concurrency fix
In `application/workflow/handlers.py::ExecuteWorkflowHandler.handle`, change the running-job query from a plain SELECT to:
```python
existing = await session.execute(
    select(JobModel)
    .where(JobModel.workflow_id == cmd.workflow_id, JobModel.status.in_(["pending", "running"]))
    .with_for_update()
)
```
Plus a unique partial index migration:
```python
op.create_index(
    "ix_workflow_unique_active_job",
    "jobs",
    ["workflow_id"],
    unique=True,
    postgresql_where=sa.text("status IN ('pending', 'running') AND workflow_id IS NOT NULL"),
)
```
Migration 025.

### Child jobs use parent created_by
Find every `JobModel(... created_by=uuid.UUID(int=0))` in `workflow_tasks.py`. Replace with `created_by=parent_job.created_by` (capture `parent_job` at top of `_run_async`).
