Close out Phase 44 with the columnar writer (Parquet + ORC via pyarrow),
the writer registry + `get_writer(format)` factory, and a `GET /file-formats`

writer fills out the format menu so users can emit Parquet/ORC alongside

## AC-1: ColumnarWriter writes Parquet round-trippable through pyarrow
```gherkin
Given a FileSchemaDefinition with file_format=PARQUET
When ColumnarWriter.write(schema, rows, output_path) runs
Then `pyarrow.parquet.read_table(output_path)` yields a table whose columns equal `schema` non-filler field names
And every cell round-trips back to the input value (strings as strings, ints as ints, decimal fields as decimal128 with field's precision/scale, floats as float64 when decimal_places=0)
And the file's compression metadata equals the writer's `compression` setting (default "snappy")
```

## AC-2: ColumnarWriter writes ORC round-trippable through pyarrow
```gherkin
Given the same row set with file_format=ORC
When ColumnarWriter.write runs
Then `pyarrow.orc.read_table(output_path)` round-trips column names and values
And ORC compression honors the writer setting (default "snappy")
```

## AC-3: ColumnarWriter type mapping is deterministic
```gherkin
Given a FileFieldDefinition
When ColumnarWriter._map_arrow_type(field) is called
Then:
  - data_type == "alphanumeric" → pa.string()
  - data_type == "numeric" and decimal_places == 0 → pa.int64()
  - data_type == "numeric" with comp_type == "comp" and length <= 9 → pa.int32()
  - data_type == "decimal" → pa.decimal128(field.length, field.decimal_places) using field.length as total precision
  - data_type == "binary" → pa.binary(field.byte_length)
  - data_type == "packed_decimal" → pa.decimal128(field.length, field.decimal_places)
And filler fields are excluded from the schema.
```

## AC-4: WriterRegistry resolves all four writers
```gherkin
Given a WriterRegistry constructed with the default factory
When get_writer(FileFormat.CSV) is called → returns a CSVWriter
When get_writer(FileFormat.FIXED_WIDTH) → FixedWidthWriter
When get_writer(FileFormat.VSAM_FIXED) → VSAMWriter
When get_writer(FileFormat.VSAM_VARIABLE) → VSAMWriter
When get_writer(FileFormat.PARQUET) → ColumnarWriter
When get_writer(FileFormat.ORC) → ColumnarWriter
And get_writer with an unsupported format raises NotFoundError("No writer registered for format: ...")
```

## AC-5: Writer registration is class-driven via supported_formats()
```gherkin
Given a registry where each writer class is registered once
When the registry computes its format → class map
Then no two writer classes claim the same FileFormat
And every FileFormat enum value has at least one writer
```

## AC-6: GET /api/v1/file-formats lists supported formats with metadata
```gherkin
Given an authenticated user
When GET /api/v1/file-formats is called
Then the response shape is { "formats": [{ "value": str, "label": str, "extension": str, "writer": str }, ...] }
And the list contains all six FileFormat values (CSV, FIXED_WIDTH, VSAM_FIXED, VSAM_VARIABLE, PARQUET, ORC)
And the `writer` field equals the class name of the resolved writer.
```

    Create `columnar_writer.py`:

    Imports: `pathlib.Path`, `decimal.Decimal`,
    `pyarrow as pa`, `pyarrow.parquet as pq`,
    `pyarrow.orc` lazily (it's an optional import on some pyarrow builds — import inside the ORC branch),
    `app.domain.synthetic.file_schema.FileSchemaDefinition, FileFieldDefinition`,
    `app.domain.synthetic.value_objects.FileFormat`,
    `app.infrastructure.writers.base_writer.BaseFileWriter, write_atomic`.

    Class `ColumnarWriter(BaseFileWriter)`:
      `__init__(self, compression: str = "snappy")` — store as `self._compression`.

      `@classmethod supported_formats(cls)`: returns `{FileFormat.PARQUET, FileFormat.ORC}`.

      `get_extension(self)`: returns `"parquet"` (callers compute the actual ext from the schema's file_format if they care; tests only check this default).

      `validate_schema(self, schema)`:
        - super().validate_schema(schema) errors first.
        - Reject formats outside {PARQUET, ORC}.
        - Reject `binary` / `packed_decimal` / signed display formats — those are mainframe-binary territory; columnar is for analytics.
        - Return errors.

      `_map_arrow_type(self, field) -> pa.DataType`:
        - is_filler → raise (callers should pre-skip).
        - alphanumeric → pa.string()
        - decimal or packed_decimal → pa.decimal128(field.length, field.decimal_places)
        - numeric: if decimal_places > 0 → pa.decimal128(field.length, field.decimal_places); elif comp_type=="comp" and length <= 9 → pa.int32(); else pa.int64().
        - binary → pa.binary(field.byte_length)
        - Any unrecognized data_type → raise NotImplementedError.

      `_build_arrow_table(self, schema, rows) -> pa.Table`:
        - emitted = [f for f in schema.fields if not f.is_filler].
        - For each emitted field, build the pa column:
          - Coerce decimals to Decimal(value).quantize(...) to match precision/scale.
          - None values stay None.
        - Use pa.schema([(f.name, _map_arrow_type(f)) for f in emitted]).
        - Return pa.Table.from_pydict({name: [...] for name in field_names}, schema=arrow_schema).

      `write(self, schema, rows, output_path) -> Path`:
        - _ensure_writable.
        - table = self._build_arrow_table(schema, rows).
        - with write_atomic(output_path, mode="wb") as handle:
          - if schema.file_format == FileFormat.PARQUET.value:
              pq.write_table(table, handle, compression=self._compression)
          - elif schema.file_format == FileFormat.ORC.value:
              from pyarrow import orc  # lazy
              orc.write_table(table, handle, compression=self._compression.upper() if self._compression else "NONE")
          - else: raise ValueError.
        - Return output_path.
  </action>

import tempfile, decimal
from pathlib import Path
import pyarrow.parquet as pq
import pyarrow.orc as orc
from app.domain.synthetic.file_schema import FileSchemaDefinition, FileFieldDefinition
from app.domain.synthetic.value_objects import FileFormat
from app.infrastructure.writers.columnar_writer import ColumnarWriter

schema = FileSchemaDefinition(
    name='t',
    fields=[
        FileFieldDefinition(name='id', data_type='numeric', length=5, byte_length=5, start_position=0),
        FileFieldDefinition(name='name', data_type='alphanumeric', length=10, byte_length=10, start_position=5),
        FileFieldDefinition(name='balance', data_type='decimal', length=10, byte_length=10, start_position=15, decimal_places=2),
    ],
    file_format=FileFormat.PARQUET.value,
)
rows = [{'id': 1, 'name': 'Alice', 'balance': 100.50}, {'id': 2, 'name': 'Bob', 'balance': None}]

with tempfile.TemporaryDirectory() as d:
    out = Path(d) / 't.parquet'
    ColumnarWriter().write(schema, rows, out)
    table = pq.read_table(out)
    assert table.column_names == ['id', 'name', 'balance']
    py = table.to_pydict()
    assert py['id'] == [1, 2]
    assert py['name'] == ['Alice', 'Bob']
    # balance is decimal128(10, 2) — first cell == Decimal('100.50'); second is None
    assert py['balance'][0] == decimal.Decimal('100.50')
    assert py['balance'][1] is None

schema_orc = FileSchemaDefinition(name='t', fields=schema.fields, file_format=FileFormat.ORC.value)
with tempfile.TemporaryDirectory() as d:
    out = Path(d) / 't.orc'
    ColumnarWriter().write(schema_orc, rows, out)
    table = orc.read_table(out)
    assert table.column_names == ['id', 'name', 'balance']

print('ColumnarWriter parquet + orc OK')
"

  <files>backend/app/infrastructure/writers/registry.py</files>
  <action>
    Create `registry.py`:

    Imports stdlib only on registration; writer modules imported lazily inside
    `create_default_registry` to avoid circular imports through pyarrow.

    Class `WriterRegistry`:
      `__init__(self)`: `self._by_format: dict[FileFormat, type[BaseFileWriter]] = {}`.

      `register(self, writer_cls: type[BaseFileWriter]) -> None`:
        - formats = writer_cls.supported_formats()
        - For each f in formats:
          - If f already registered to a different class: raise ValueError("Format X already registered to Y").
          - else: self._by_format[f] = writer_cls.

      `get_writer(self, fmt: FileFormat) -> BaseFileWriter`:
        - cls = self._by_format.get(fmt)
        - if cls is None: raise `NotFoundError(message=f"No writer registered for format: {fmt.value}", code="writer_not_found")`.
        - return cls()

      `supported_formats(self) -> list[FileFormat]`:
        - return sorted list of self._by_format keys (by value).

    Function `create_default_registry() -> WriterRegistry`:
      - Lazy imports of CSVWriter, FixedWidthWriter, VSAMWriter, ColumnarWriter.
      - Build registry; register each class once.
      - Return.

    Module-level `_singleton: WriterRegistry | None = None`.
    Function `default_registry() -> WriterRegistry`:
      - if _singleton is None: _singleton = create_default_registry()
      - return _singleton.

    Convenience `get_writer(fmt: FileFormat) -> BaseFileWriter`:
      - return `default_registry().get_writer(fmt)`.
  </action>

    ```python
    from app.domain.synthetic.value_objects import FileFormat as _FileFormat
    from app.infrastructure.writers.registry import default_registry as _default_writer_registry


    @router.get("/file-formats", tags=["file-formats"])
    async def list_file_formats(current_user: dict = Depends(get_current_user)):
        """List supported file output formats for file-based synthetic generation."""
        registry = _default_writer_registry()
        labels = {
            "csv": "CSV",
            "fixed_width": "Fixed-width",
            "vsam_fixed": "VSAM Fixed",
            "vsam_variable": "VSAM Variable",
            "parquet": "Parquet",
            "orc": "ORC",
        }
        extensions = {
            "csv": "csv",
            "fixed_width": "txt",
            "vsam_fixed": "vsam",
            "vsam_variable": "vsam",
            "parquet": "parquet",
            "orc": "orc",
        }
        formats = []
        for fmt in registry.supported_formats():
            writer = registry.get_writer(fmt)
            formats.append({
                "value": fmt.value,
                "label": labels.get(fmt.value, fmt.value),
                "extension": extensions.get(fmt.value, writer.get_extension()),
                "writer": writer.__class__.__name__,
            })
        return {"formats": formats}
    ```
