<objective>
## Goal
Establish the writer module structure and ship the two lowest-risk writers:
`BaseFileWriter` ABC + `CSVWriter` + `FixedWidthWriter`, each round-trip
readable so format-fidelity bugs surface at unit-test time rather than in
Phase 45.

## Purpose
Phase 43 defined the input contract (`FileSchemaDefinition`). Phase 44 is
the output side. Plan 44-01 lands the writer abstraction the other two
plans (44-02 VSAM, 44-03 Columnar + Registry) build on, and the two
text-format writers most Ameritas users will actually use day-to-day. The
ABC defined here is the surface Phase 46's `FileSetOrchestrator` will
program against.

<acceptance_criteria>

## AC-1: `BaseFileWriter` ABC defines the writer contract cleanly
```gherkin
Given the writers module
When `BaseFileWriter` is imported
Then it is an abstractmethod-bearing ABC with:
  - `write(schema: FileSchemaDefinition, rows: list[dict], output_path: Path) -> Path` (abstract)
  - `get_extension() -> str` (abstract)
  - `validate_schema(schema: FileSchemaDefinition) -> list[str]` (concrete default — delegates to schema.validate())
  - `supported_formats() -> set[FileFormat]` (abstract — class-level capability declaration)
And it has zero domain-layer dependencies beyond `FileSchemaDefinition`,
`FileFieldDefinition`, and `FileFormat`.
And it does NOT import pyarrow, EBCDIC codecs, or any format-specific deps.
```

## AC-2: `write_atomic()` helper writes to a sibling tmp file then renames
```gherkin
Given a writer's `write()` method needs crash-safe output
When `write_atomic(output_path, callback)` is invoked
Then `callback(tmp_file_handle)` is called with a temp file handle in the
  target directory whose name is `.{output_path.name}.tmp.{uuid4}`
And on success the temp file is `os.replace(...)`-d onto `output_path`
And on exception the temp file is unlinked and the exception re-raised
And the target file never exists in a partially-written state.
```

## AC-3: `CSVWriter` produces standards-compliant CSV
```gherkin
Given a FileSchemaDefinition with file_format=CSV and a list of row dicts
When CSVWriter.write(schema, rows, output_path) runs
Then the output is a valid RFC 4180-style CSV with:
  - One header row using `field.name` order from `schema.fields` (filler fields skipped)
  - One row per dict, values pulled by field name
  - Configurable delimiter (default ","), quote char (default '"'), line terminator (default "\r\n")
  - Configurable encoding (default "utf-8"), with optional BOM toggle (default OFF)
  - Values containing the delimiter, quote, CR, or LF are quoted
  - None / missing keys serialized as the empty string
  - Floats serialized with the schema field's `decimal_places` (no trailing scientific notation)
And `get_extension()` returns "csv"
And `supported_formats()` returns `{FileFormat.CSV}`.
```

## AC-4: `FixedWidthWriter` writes position-correct ASCII records
```gherkin
Given a FileSchemaDefinition with file_format=FIXED_WIDTH and rows
When FixedWidthWriter.write(schema, rows, output_path) runs
Then each output record is exactly `schema.compute_record_length()` bytes long
And alphanumeric / decimal-as-text fields are right-padded with spaces (configurable pad_char)
And numeric fields are left-padded with zeros (configurable num_pad_char)
And signed numeric fields render the sign per `signed` flag in the schema (leading sign by default)
And decimals render `length` total characters with the decimal point implied (no literal '.' written) when `field.metadata.implied_decimal` is true, else with a literal '.'
And filler fields render their `byte_length` worth of pad chars
And REDEFINES fields are NOT serialized again (their position is shared with the redefined field)
And `get_extension()` returns "txt"
And `supported_formats()` returns `{FileFormat.FIXED_WIDTH}`.
```

## AC-5: Both writers validate schema before writing any bytes
```gherkin
Given a FileSchemaDefinition with overlapping positions or duplicate field names
When writer.write(schema, rows, output_path) is called
Then a ValueError is raised before the temp file is opened
And the message starts with "Schema validation failed:" followed by the joined `schema.validate()` errors.
```

## AC-6: Round-trip tests pass end-to-end for both writers
```gherkin
Given a representative FileSchemaDefinition and a list of test rows
When the writer produces a file and the file is read back:
  - CSV via `csv.DictReader`
  - Fixed-width via byte-slice extraction at the schema's positions
Then every row's typed values equal the input rows after type coercion
And the byte-length invariant holds for every fixed-width record.
```

## AC-7: Writers are sync; output path is honored
```gherkin
Given `output_path` is a path inside a directory the process can write to
When write() returns
Then the returned Path equals the input output_path
And the parent directory was not modified beyond the new file
And the writer methods are plain (non-async) — the calling Celery task is async.
```

  <action>
    1. Create `backend/app/infrastructure/writers/__init__.py` (empty package marker).

    2. Create `backend/app/infrastructure/writers/base_writer.py` with:

       Module docstring: "File writers for the v0.7 synthetic file output pipeline. Each writer consumes a FileSchemaDefinition + row dicts and emits one file in the corresponding format."

       Imports: `abc`, `contextlib`, `os`, `uuid`, `pathlib.Path`, `typing.Iterator`,
       `app.domain.synthetic.file_schema.FileSchemaDefinition`,
       `app.domain.synthetic.value_objects.FileFormat`.

       Class `BaseFileWriter(abc.ABC)`:
         - `@abc.abstractmethod write(self, schema: FileSchemaDefinition, rows: list[dict], output_path: Path) -> Path`
         - `@abc.abstractmethod get_extension(self) -> str`
         - `@classmethod @abc.abstractmethod supported_formats(cls) -> set[FileFormat]`
         - Concrete `validate_schema(self, schema: FileSchemaDefinition) -> list[str]`:
           returns `schema.validate()` (delegates to domain).
         - Concrete `_ensure_writable(self, schema, rows, output_path)`:
           raises `ValueError("Schema validation failed: " + "; ".join(errors))` if `validate_schema` is non-empty;
           ensures `output_path.parent.exists()` (raises FileNotFoundError otherwise).

       Module-level function `write_atomic(output_path: Path, mode: str = "wb") -> Iterator[IO]`:
         - Decorated with `@contextlib.contextmanager`.
         - Builds `tmp_path = output_path.parent / f".{output_path.name}.tmp.{uuid.uuid4().hex}"`.
         - Opens with `open(tmp_path, mode)`; yields the handle.
         - On clean exit: flush + fsync, `os.replace(tmp_path, output_path)`.
         - On exception: close handle, `tmp_path.unlink(missing_ok=True)`, re-raise.

    3. Keep this file free of any format-specific imports. Only stdlib + domain.
  </action>

  <files>backend/app/infrastructure/writers/csv_writer.py</files>
  <action>
    Create `csv_writer.py`:

    Imports: `csv`, `io`, `pathlib.Path`,
    `app.domain.synthetic.file_schema.FileSchemaDefinition`,
    `app.domain.synthetic.value_objects.FileFormat`,
    `app.infrastructure.writers.base_writer.BaseFileWriter, write_atomic`.

    Class `CSVWriter(BaseFileWriter)`:
      `__init__(self, delimiter=",", quotechar='"', line_terminator="\r\n", encoding="utf-8", include_header=True, write_bom=False)`
      — store all as `self._...`.

      `@classmethod supported_formats(cls) -> set[FileFormat]`: returns `{FileFormat.CSV}`.

      `get_extension(self) -> str`: returns `"csv"`.

      `write(self, schema, rows, output_path) -> Path`:
        1. `self._ensure_writable(schema, rows, output_path)`.
        2. Build the list of emitted field names — `[f.name for f in schema.fields if not f.is_filler]`.
        3. Open `write_atomic(output_path, mode="wb")`:
           a. If `write_bom` and encoding is `utf-8`: write `b"\xef\xbb\xbf"`.
           b. Wrap the binary handle with `io.TextIOWrapper(handle, encoding=encoding, newline="")` (newline="" prevents csv module from translating).
           c. Create `csv.writer(text_handle, delimiter=self._delimiter, quotechar=self._quotechar, quoting=csv.QUOTE_MINIMAL, lineterminator=self._line_terminator)`.
           d. If `include_header`, write the field-name header row.
           e. For each row dict, build the row tuple:
              - For each emitted field, fetch `row.get(name)`.
              - If None: serialize as empty string "".
              - If a float and the field has `decimal_places > 0`: format with `f"{value:.{field.decimal_places}f}"`.
              - Else: `str(value)`.
              - csv module handles delimiter/quote/CR/LF quoting via QUOTE_MINIMAL.
           f. Detach the TextIOWrapper before atomic rename (call `text_handle.flush()`, then `text_handle.detach()` so the underlying binary handle isn't closed twice).
        4. Return `output_path`.

    Avoid: opening the output path directly — must go through `write_atomic`.
    Avoid: writing the header twice on partial restart (single-pass write).
  </action>
  <verify>
    cd backend && python -c "
import tempfile, csv as csvm
from pathlib import Path
from app.domain.synthetic.file_schema import FileSchemaDefinition, FileFieldDefinition
from app.domain.synthetic.value_objects import FileFormat
from app.infrastructure.writers.csv_writer import CSVWriter

schema = FileSchemaDefinition(
    name='customers',
    fields=[
        FileFieldDefinition(name='id', data_type='numeric', length=4, byte_length=4, start_position=0),
        FileFieldDefinition(name='name', data_type='alphanumeric', length=10, byte_length=10, start_position=4),
        FileFieldDefinition(name='balance', data_type='decimal', length=10, byte_length=10, start_position=14, decimal_places=2),
    ],
    file_format=FileFormat.CSV.value,
    encoding='utf-8',
)
rows = [
    {'id': 1, 'name': 'Alice', 'balance': 100.5},
    {'id': 2, 'name': 'B,ob', 'balance': None},
    {'id': 3, 'name': 'Carol \"Q\"', 'balance': 42.0},
]

with tempfile.TemporaryDirectory() as d:
    out = Path(d) / 'customers.csv'
    CSVWriter().write(schema, rows, out)
    with open(out, 'r', newline='', encoding='utf-8') as f:
        read = list(csvm.DictReader(f))

assert len(read) == 3, f'expected 3 rows, got {len(read)}'
assert read[0]['name'] == 'Alice'
assert read[1]['name'] == 'B,ob'  # comma preserved through quoting
assert read[1]['balance'] == ''   # None → empty
assert read[0]['balance'] == '100.50'  # decimal_places=2
print('CSVWriter round-trip OK')
"

  <name>Task 3: Implement FixedWidthWriter</name>
  <files>backend/app/infrastructure/writers/fixed_width_writer.py</files>
  <action>
    Create `fixed_width_writer.py`:

    Imports: `pathlib.Path`,
    `app.domain.synthetic.file_schema.FileSchemaDefinition, FileFieldDefinition`,
    `app.domain.synthetic.value_objects.FileFormat`,
    `app.infrastructure.writers.base_writer.BaseFileWriter, write_atomic`.

    Class `FixedWidthWriter(BaseFileWriter)`:
      `__init__(self, pad_char=" ", num_pad_char="0", record_terminator=b"\n", encoding="ascii", leading_sign=True)`
      — store as `self._...`.

      `@classmethod supported_formats(cls) -> set[FileFormat]`: returns `{FileFormat.FIXED_WIDTH}`.

      `get_extension(self) -> str`: returns `"txt"`.

      Helper `_render_field(self, field: FileFieldDefinition, value) -> bytes`:
        - If `field.is_filler`: return `self._pad_char.encode(self._encoding) * field.byte_length`.
        - If value is None and field.nullable: return null bytes (`self._pad_char.encode(self._encoding) * field.byte_length`).
        - Branch by `field.data_type`:
          - `"alphanumeric"`: encode str(value) in `self._encoding`, right-pad with `pad_char` to `field.byte_length`. Truncate (with warning via structlog) if too long.
          - `"numeric"`: convert to int, render as decimal digits, left-pad with `num_pad_char` to `field.length`. If signed and value is negative: leading sign char ("-") consumes 1 char of width; if non-negative and `signed`, leading sign char " " or "+". The encoded result must equal `field.byte_length` bytes.
          - `"decimal"`: format with `decimal_places`. If `field.metadata.get("implied_decimal")` is True (we check `schema.metadata.get("implied_decimal", False)` in `write()` since `FileFieldDefinition` has no per-field metadata field), strip the literal '.' and left-pad with num_pad_char to `field.length`. Otherwise render with the literal '.' included in the width.
          - Other types: raise NotImplementedError (binary / packed_decimal handled by VSAMWriter in 44-02).
        - After encoding, assert the produced bytes length equals `field.byte_length`; raise ValueError if not.

      `write(self, schema, rows, output_path) -> Path`:
        1. `self._ensure_writable(schema, rows, output_path)`.
        2. Pre-sort fields by `start_position` for emission order; skip fields with `redefines != None` (redefines share storage with their target).
        3. Open `write_atomic(output_path, mode="wb")`:
           a. For each row in `rows`:
              - Build a `bytearray` of `schema.compute_record_length()` bytes initialized to `pad_char`.
              - For each non-redefining field, `value = row.get(field.name)`; place `_render_field(field, value)` into `record[field.start_position:field.start_position + field.byte_length]`.
              - Assert `len(record) == schema.compute_record_length()`.
              - Write `bytes(record) + self._record_terminator` to the handle.
        4. Return `output_path`.

    Note: schema-level `implied_decimal` toggle lives in `schema.metadata` since FileFieldDefinition is frozen and we don't want to widen it in this plan. Per-field override is a v0.8 enhancement.
  </action>
  <verify>

import tempfile
from pathlib import Path
from app.domain.synthetic.file_schema import FileSchemaDefinition, FileFieldDefinition
from app.domain.synthetic.value_objects import FileFormat
from app.infrastructure.writers.fixed_width_writer import FixedWidthWriter

schema = FileSchemaDefinition(
    name='positions',
    fields=[
        FileFieldDefinition(name='id', data_type='numeric', length=5, byte_length=5, start_position=0),
        FileFieldDefinition(name='name', data_type='alphanumeric', length=10, byte_length=10, start_position=5),
        FileFieldDefinition(name='price', data_type='decimal', length=8, byte_length=8, start_position=15, decimal_places=2),
        FileFieldDefinition(name='', data_type='alphanumeric', length=2, byte_length=2, start_position=23, is_filler=True),
    ],
    file_format=FileFormat.FIXED_WIDTH.value,
    encoding='ascii',
    record_length=25,
)
rows = [
    {'id': 1, 'name': 'Alice', 'price': 99.5},
    {'id': 42, 'name': 'Bob', 'price': 100.0},
]

with tempfile.TemporaryDirectory() as d:
    out = Path(d) / 'positions.txt'
    FixedWidthWriter().write(schema, rows, out)
    data = out.read_bytes()

# Each record = 25 bytes + 1 newline = 26 bytes; 2 records = 52 bytes
assert len(data) == 52, f'expected 52 bytes, got {len(data)}'
# Inspect first record
rec0 = data[:25]
assert rec0[0:5] == b'00001', rec0[0:5]
assert rec0[5:15] == b'Alice     ', rec0[5:15]
assert rec0[15:23] == b'00099.50', rec0[15:23]
assert rec0[23:25] == b'  ', rec0[23:25]  # filler
print('FixedWidthWriter byte-positions OK')
"
