<objective>
## Goal
Build the full quality visualization suite using Recharts: composite score gauge, per-column distribution overlays (real vs synthetic), correlation heatmap triplets, and privacy metrics display — the visual proof that synthetic data is statistically faithful.

## Purpose
This is what competitors (Gretel SQS, MOSTLY AI) use to prove data quality. Without these charts, DataWrangler's quality evaluation (Phase 11 backend) is invisible to users. These visualizations are the "see it to believe it" evidence.

## Output
- Composite score gauge (0-100 with color gradient)
- Per-column distribution overlay charts (real=black, synthetic=blue)
- Correlation heatmap (original vs synthetic vs difference)
- Privacy metrics cards (DCR, identical matches)
- Fully wired to GET /synthetic/configs/{id}/quality API
</objective>
