<objective>
Fix 5 critical/high UI blockers: subsetting placeholder connection ID, SSE auth token, RBAC manager implementation, connection edit functionality, and jobs pagination.
</objective>

<acceptance_criteria>
## AC-1: Subsetting Connection Selector
Given the subsetting config form, when user creates a config, then a real connection is selected from available connections (dropdown), not a hardcoded "placeholder" string.

## AC-2: SSE Auth Token
Given httpOnly cookie auth, when SSE EventSource connects, then credentials are included. Since tokens are in httpOnly cookies, EventSource must use withCredentials (not query param token).

## AC-3: RBAC Manager
Given the admin page, when user views RBAC, then they see a real member list with invite, role assignment (Admin/Editor/Viewer), and removal. Wired to API endpoints.

## AC-4: Connection Edit
Given an existing connection, when user clicks edit, then the connection form drawer opens pre-filled with current values and submits an update (PUT). Store has updateConnection method.

## AC-5: Jobs Pagination
Given a job list with many results, when user clicks page 2/3/N, then fetchJobs is called with correct page offset and results update. Pagination component supports arbitrary page counts with ellipsis.
</acceptance_criteria>
