## Goal
Replace the sidebar-based AppShell with a two-bar TopShell (dark global nav +
workspace-scoped tab bar with a right-pinned Generate Data ▾ split-button).
Add UX design tokens (palette, density). All existing pages migrate
automatically because AppShell is preserved as a thin alias.

## Output
- `globals.css` — design tokens for the UX palette (CSS variables added under
  existing :root, with dark-mode-override layer for the global bar)
- `top-shell.tsx` — new shell with dark global bar + light content surface
- `global-nav-bar.tsx` — Projects · Generator Presets · Sensitivity Rules ·
  Admin · (search · help · user · assistant)
- `workspace-tab-bar.tsx` — project-scoped tabs + Generate Data CTA on the right
- `generate-data-button.tsx` — split button covering all workspace verbs
- `app-shell.tsx` — kept as a thin alias delegating to TopShell so existing
  pages don't need to change.
</objective>
