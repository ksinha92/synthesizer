# Phase 61 Plan 02 — SSR Fix + Large-File Splits + Tooling

## F17 — `/projects` SSR `useContext` null

### Diagnosis
1. `cd frontend && npm ls react react-dom` — check for duplicate React installations.
2. Inspect `frontend/src/app/projects/page.tsx` and its imports. Look for any Provider components imported directly into the page (which is a server component by default in Next.js App Router).
3. Inspect any `"use client"` directives at top of imported modules; reverse the import chain — a server component cannot import a client-side context.
4. Check `frontend/src/app/layout.tsx` for Provider wrapping; the providers should wrap `{children}` but be in a client component if they use context.

### Likely fix
Add `"use client"` to the topmost component that uses context, or move provider initialization into a dedicated `Providers.tsx` client component imported into `layout.tsx`.

### Verification
