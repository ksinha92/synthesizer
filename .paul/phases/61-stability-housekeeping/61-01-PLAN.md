# Phase 61 Plan 01 — Ephemeral Data-Copy Controller

## Architecture

Each ephemeral environment provisions a sidecar Docker container running the appropriate DB engine. The host binds a host-port; the connection string returned to the user points at `host.docker.internal:<port>` (or env-configured external host). After TTL expires (default 24h, cap 30d), the container is stopped and removed.

```
POST /ephemeral  →  JobModel(pending)
                 →  run_ephemeral_provision_task.delay(env_id)
                    ├── DockerProvisioner.create_container(engine, db_name, user, password)
                    ├── _wait_for_ready(container)  # ping every 1s up to 60s
                    ├── _copy_data(source_connection, target, masking_policy?)
                    └── mark_environment_ready(env_id, connection_string)
```

### NEW `backend/app/infrastructure/ephemeral/data_copy.py`
- `async def copy_data(source: Connection, target_dsn: str, masking_policy_id: uuid.UUID | None) -> int`:
  - Connect to source via existing connector registry.
  - For each table in source schema: copy rows in batches of 1000.
  - If `masking_policy_id`, apply rules to each row before writing.
  - Return rows-copied count.
