<objective>
WCAG 2.1 AA compliance pass on all modals/drawers, keyboard navigation, focus management, mobile responsiveness on high-traffic pages, and comprehensive E2E test coverage.
</objective>

<acceptance_criteria>
## AC-1: Modal/Dialog Accessibility
Given any modal or drawer in the app, when opened, then it has role="dialog", aria-modal="true", aria-labelledby pointing to its title, focus trapped inside, Escape key closes it, and focus returns to the trigger on close.

## AC-2: Keyboard Navigation + Focus Styling
Given any interactive element, when navigating with Tab key, then a visible focus ring appears (focus-visible). All icon-only buttons have aria-label. Skip-to-content link exists.

## AC-3: Mobile Responsiveness
Given high-traffic pages (dashboard, projects, jobs, connections), when viewed on mobile (< 768px), then layout adapts: drawers become full-width, tables scroll horizontally, touch targets are >= 44px.

## AC-4: E2E Test Coverage
Given the Playwright test suite, when run, then tests cover: keyboard navigation through main flows, modal open/close/escape, theme toggle, sidebar collapse, mobile viewport rendering.
</acceptance_criteria>
