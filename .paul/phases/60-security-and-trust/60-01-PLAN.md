### Signature & verification logic
```python
# Server-side dispatch (dispatcher.py):
import hmac, hashlib, time, json

ts = str(int(time.time()))
body = json.dumps(payload).encode()
signing_string = f"{ts}.{body.decode()}"

if webhook.secret_encrypted:
    secret = fernet.decrypt(webhook.secret_encrypted)
    sig = hmac.new(secret, signing_string.encode(), hashlib.sha256).hexdigest()
elif webhook.secret_hash and webhook.legacy_signing:
    # Legacy path during deprecation window
    sig = hmac.new(webhook.secret_hash.encode(), body, hashlib.sha256).hexdigest()
    headers["X-Webhook-Legacy-Signing"] = "true"
else:
    raise ValueError("no signing material")

headers["X-Webhook-Signature"] = f"sha256={sig}"
headers["X-Webhook-Timestamp"] = ts
```

Receivers compute `hmac(secret, f"{ts}.{body}")` and compare. Constant-time compare (`hmac.compare_digest`).
