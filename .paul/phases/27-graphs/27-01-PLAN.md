<objective>
## Goal
Build ReactFlow-based interactive graphs for FK relationship visualization (discovery) and subsetting dependency visualization — replacing the text-only tree/form UIs with proper graph visualization.

## Purpose
Graph visualization is a core spec feature (DATAWRANGLER.md requirement #4 + #7). Discovery should show tables as nodes connected by FK edges. Subsetting should show traversal direction with colored arrows on the same graph. Without these, users can't see data relationships.

## Output
- RelationshipGraph: ReactFlow with table nodes + FK edges in discovery
- DependencyGraph: ReactFlow with traversal arrows + row counts in subsetting
- Discovery page: new "Graph" tab alongside Schema Explorer + PII Results
- Subsetting page: graph replaces placeholder, dry-run table populated
</objective>

## Prior Work
- Phase 20: ReactFlow workflow canvas (reuse node patterns + dynamic import)
- Phase 5: Discovery API returns relationships
- Phase 14: Subsetting API returns dry-run analysis
</context>

<acceptance_criteria>

## AC-1: Relationship graph shows tables as nodes connected by FK edges
```gherkin
Given discovered relationships for a schema
When the Graph tab is selected on the discovery page
Then ReactFlow renders table nodes (name + row count badge)
And FK relationships render as directed edges (child → parent)
And clicking a table node shows its columns in the detail panel
```

## AC-2: Subsetting graph shows traversal direction with visual indicators
```gherkin
Given a subsetting config with root table and traversal direction
When the subsetting page loads
Then ReactFlow renders the dependency graph with the root table highlighted
And upstream tables show blue arrows, downstream show green arrows
And each node shows estimated row count from dry-run
```

## AC-3: Dry-run analysis table populates from API
```gherkin
Given a subsetting config
When "Analyze (Dry Run)" is clicked
Then the table shows per-table: name, full count, subset count, percentage
And a total row at the bottom
```
