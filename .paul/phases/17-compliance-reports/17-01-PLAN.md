<objective>
## Goal
Implement HIPAA, GDPR, and CCPA compliance report generators — each with regulation-specific sections, PDF output, and a compliance dashboard showing PII coverage status across the project.

## Purpose
Ameritas requires all three compliance frameworks equally. Reports prove that PII has been detected, classified, and masked — the audit evidence that regulators and internal compliance teams need.

## Output
- Compliance domain: ComplianceReport entity, per-regulation reporter services
- 3 report generators: HIPAAReporter, GDPRReporter, CCPAReporter
- PDF generation via reportlab/weasyprint
- Compliance API: generate, list, download
- Frontend: report generator form, report list with download
</objective>

<context>
## Prior Work
- Phase 5: PII detection results (what's been detected)
- Phase 13: Masking results (what's been masked)
</context>

<acceptance_criteria>

## AC-1: HIPAA report covers PHI inventory and encryption status
```gherkin
Given a project with PII detections and masking policies
When a HIPAA compliance report is generated
Then it includes: PHI inventory (all PII columns with types), access controls summary,
  encryption status (masked vs unmasked count), masking coverage percentage
And the report is stored as JSON + downloadable as PDF
```

## AC-2: GDPR report covers data mapping and right-to-erasure
```gherkin
Given a project with PII detections
When a GDPR compliance report is generated
Then it includes: data mapping (all PII by category), processing purpose placeholders,
  DPIA assessment structure, right-to-erasure documentation
```

## AC-3: CCPA report covers consumer data categories
```gherkin
Given a project with PII detections
When a CCPA compliance report is generated
Then it includes: consumer data categories inventory, data sources,
  business purpose documentation, opt-out capability documentation
```

## AC-4: Compliance API and frontend work end-to-end
```gherkin
Given an authenticated user
When POST /compliance/reports is called with {regulation: "hipaa", date_range}
Then a report is generated and stored
And GET /compliance/reports lists all reports with download links
And the frontend shows report generator form + report list + PII coverage summary
```
