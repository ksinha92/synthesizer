- Synthetic page: engine selector cards, config form, preview table
- Zustand stores for discovery and synthetic state

## AC-1: Schema Explorer shows tree with column detail and PII indicators
```gherkin
Given a project with completed discovery
When the user visits /projects/{id}/discovery
Then a split-pane layout shows: schema tree (left) + column detail (right)
And the tree displays schemas → tables → columns with PII indicator dots (red/yellow)
And clicking a column shows its detail: data type, stats, PII classification, confidence, detector
And a "Run Discovery" button triggers async discovery via API (returns job ID)
```

## AC-2: PII Results table shows classifications with filters and override
```gherkin
Given a project with PII detections
When the PII tab is active on the discovery page
Then a table shows all PII columns: table, column, type, confidence, detector, classification
And confidence badges are color-coded (green >= 0.65, yellow 0.4-0.65, red < 0.4)
And filters allow filtering by PII type, classification status, confidence range
And clicking "Override" on a column opens a dropdown to change PII type with a note field
```

## AC-3: Synthetic page has engine selector, config, and preview
```gherkin
Given an authenticated user visits /projects/{id}/synthetic
When the page loads
Then 3 engine cards display: Faker (Fast), Statistical (Accurate), LLM (Intelligent)
And selecting Faker shows a config form with table/row count selection
And "Preview" generates 10 rows synchronously and displays in a table
And "Generate" dispatches async job (returns job ID, 202)
```
