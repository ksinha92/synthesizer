<objective>
## Goal
Create the FastAPI backend with full DDD folder structure, shared domain base classes, DI container, first bounded context (connection), Docker Compose dev environment, and Alembic migration setup — so subsequent phases have a working foundation to build on.

## Purpose
This is the foundation everything else depends on. The DDD structure enforces architectural discipline from day one. The Docker environment means any developer can `make dev` and have a running system.

## Output
- `backend/` — FastAPI application with DDD layers (domain/application/infrastructure/api)
- `backend/app/domain/shared/` — Base Entity, AggregateRoot, ValueObject, DomainEvent, Repository ABC
- `backend/app/domain/connection/` — First bounded context (entities, value objects, repository ABC, services, events)
- `backend/app/container.py` — dependency-injector DI container
- `docker-compose.dev.yml` — PostgreSQL, Redis, backend, worker, Flower
- `Makefile` — dev, test, lint, migrate targets
- `.env.example` — all configuration variables
</objective>

       - repository.py: ConnectionRepository(Repository) ABC with find_by_project_id method
       - services.py: ConnectionTestService with test_connection(connection) -> bool (placeholder)
       - events.py: ConnectionTested(DomainEvent), ConnectionFailed(DomainEvent)
       - CRITICAL: Domain layer must NOT import from fastapi, sqlalchemy, celery, or any infrastructure package.

    5. Create backend/app/container.py:
       - dependency-injector DeclarativeContainer
       - Configuration provider from config.py
       - Database provider (placeholder for async SQLAlchemy engine)

    6. Create backend/app/main.py:
       - FastAPI app factory function create_app()
       - Wire DI container
       - Include v1 router
       - Configure CORS middleware
       - structlog JSON logging setup

    7. Create backend/app/api/v1/health.py:

       - GET /api/v1/ready returning readiness status
       - All dependency checks (db, redis) must have a 3-second timeout — do not let a hanging connection block the health endpoint indefinitely <!-- audit-added -->
       - Return degraded status (200 with "degraded" flag) if a non-critical service is down, 503 only if critical services are unreachable <!-- audit-added -->

    8. Create backend/app/infrastructure/persistence/database.py:
