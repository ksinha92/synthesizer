<objective>
## Goal
Build a 5-step onboarding wizard for first-time users and add progressive disclosure help tooltips across config forms — so new users get productive in 15 minutes.

## Output
- OnboardingWizard: 5-step stepper (Create Project → Add Connection → Run Discovery → Review PII → Apply Masking)
- HelpTooltip: reusable component for field-level help text
- Sidebar checklist showing onboarding progress
</objective>

<acceptance_criteria>

## AC-1: Onboarding wizard guides first-time users
```gherkin
Given a user who hasn't completed onboarding (no localStorage flag)
When they visit the dashboard
Then a wizard overlay appears with step 1 "Create your first project"
And each step has contextual guidance pointing to the relevant UI area
And "Skip tour" dismisses with "don't show again" persistence
And completing all 5 steps shows a congratulations message
```

## AC-2: Help tooltips on config forms
```gherkin
Given any configuration form (connections, masking rules, synthetic config)
When the user hovers/clicks a help icon (?) next to a field
Then a tooltip shows purpose + impact description for that field
```
