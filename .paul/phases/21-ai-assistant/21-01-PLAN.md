<objective>
## Goal
Build the AI assistant sidebar — a conversational interface available on every page that can query PII status, suggest masking rules, check job status, and explain schemas using the LLM provider.

## Purpose
This is the competitor-informed feature (MOSTLY AI, Immuta Copilot, Databricks Genie). Instead of navigating menus, users type natural language: "Which tables have unmasked PII?" → instant answer with action buttons.

## Output
- Backend: /assistant/chat endpoint (streams LLM response with context)
- Frontend: collapsible right-side panel with chat UI, action buttons in responses
</objective>

<context>
## Prior Work
- Phase 6: LLM provider (Claude + Ollama) — used for chat completions
- Phase 4: Header scaffold has assistant placeholder
</context>

<acceptance_criteria>

## AC-1: Assistant endpoint processes queries with project context
```gherkin
Given an authenticated user with a project
When POST /assistant/chat is called with {message, project_id}
Then the LLM receives context (project name, connection count, PII summary, recent jobs)
And returns a helpful response
And the response includes action suggestions where applicable
```

## AC-2: Frontend sidebar renders chat with action buttons
```gherkin
Given any page in the app
When the user clicks the assistant icon in the header
Then a sidebar panel slides in from the right (400px, resizable)
And the user can type messages and receive streamed responses
And responses with actions show clickable buttons (e.g., "Auto-mask all PII" → navigates to masking)
And the sidebar is collapsible to an icon
```

</acceptance_criteria>
