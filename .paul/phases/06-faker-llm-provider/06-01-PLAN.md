<objective>
## Goal
Implement the Faker synthetic engine, LLM provider abstraction (Claude API + Ollama), synthetic bounded context, and generation API endpoints — so the platform can generate realistic test data via Faker (fast) and wire the LLM provider that Phase 5's PII Layer 4 needs.

## Purpose
Faker is the first of 3 synthetic engines. It handles 80% of generation use cases (PII-type-aware fake data, constraint handling, FK ordering). The LLM provider abstraction is also critical because Phase 5's PII detection Layer 4 is currently a placeholder — this phase makes it functional.

- `backend/app/infrastructure/ai/llm_provider.py` — LLMProvider ABC
- `backend/app/infrastructure/ai/claude_provider.py` — Claude API via Anthropic SDK
- `backend/app/infrastructure/ai/ollama_provider.py` — Self-hosted Ollama
- `backend/app/infrastructure/engine/faker_engine.py` — Faker synthetic engine
- `backend/app/domain/synthetic/` — Synthetic bounded context
- `backend/app/api/v1/synthetic.py` — Synthetic generation endpoints
- Updated PII detector to use real LLM provider
</objective>

```gherkin
Given LLM_PROVIDER is set to "claude" with a valid CLAUDE_API_KEY
When the LLM provider's complete() method is called with a prompt
Then it returns a text response from the Claude API
And when LLM_PROVIDER is set to "ollama"
Then it calls the Ollama local API at OLLAMA_URL
And when the provider is unreachable, it raises AuthenticationError with clear message
And the provider is selected via config, not hardcoded
```

## AC-2: Faker engine generates PII-type-aware data with FK ordering
```gherkin
Given a synthetic config specifying tables and row counts
When the FakerEngine.generate() method is called
Then it generates data for each table in topological order (parents before children)
And columns with detected PII types use appropriate Faker providers (email→fake.email(), ssn→fake.ssn(), etc.)
And FK columns reference valid parent IDs
And non-PII columns generate type-appropriate data (int→random int, varchar→random string, etc.)
```

And all endpoints require auth and validate project ownership
