<objective>
## Goal
Build the notification center (bell icon dropdown with unread count, action buttons) and project activity feed — replacing the placeholder bell icon with a real notification system.

## Purpose
Competitor-informed feature #3 (Collibra, Snowflake). Users need to know when jobs complete, fail, or need attention without manually checking the jobs page. Activity feed provides per-project audit of who did what.

## Output
- NotificationCenter: bell dropdown, unread badge, action items
- NotificationStore: in-app notifications from job events
- ActivityFeed: project detail timeline
</objective>

<acceptance_criteria>

## AC-1: Notification center shows job events with actions
```gherkin
Given job events (completed, failed)
When the user clicks the bell icon in the header
Then a dropdown shows notification list with: icon, message, time, action button
And unread count badge shows on the bell icon
And "Mark all read" clears the badge
```

## AC-2: Activity feed shows project timeline
```gherkin
Given a project with recent actions
When the project detail page loads
Then an activity feed shows: who did what, when (e.g., "John ran discovery — 2 hours ago")
```

</acceptance_criteria>
