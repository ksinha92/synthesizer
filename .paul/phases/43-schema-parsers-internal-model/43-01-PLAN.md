<objective>
## Goal
Create the FileSchemaDefinition domain model (the unified internal representation all schema sources produce and all file writers consume) and implement a COBOL copybook parser that converts PIC clauses into FileSchemaDefinition instances.

## Purpose
This is the foundation for the entire v0.7 file-based synthetic data generation feature. Every subsequent phase (writers, profilers, orchestration, frontend) depends on FileSchemaDefinition as the common contract. The copybook parser enables mainframe-oriented users to upload existing COBOL copybooks and generate synthetic VSAM/flat files from them.

- `backend/app/domain/synthetic/file_schema.py` — New domain value objects (FileFormat, EncodingType, CompType, FileFieldDefinition, FileSchemaDefinition, FileSetDefinition)

- `backend/app/infrastructure/parsers/__init__.py` — New package

## AC-3: Copybook parser handles standard PIC clauses
```gherkin
Given a COBOL copybook string containing level numbers, PIC clauses, and COMP types
When parsed by CopybookParser.parse()
Then it returns a FileSchemaDefinition with correct field names, types, lengths, positions
And PIC X(n) maps to alphanumeric with length n
And PIC 9(n) maps to numeric with length n
And PIC 9(n)V9(m) maps to decimal with n integer + m decimal digits
And PIC S9(n) COMP-3 maps to packed decimal with byte_length = ceil((total_digits + 1) / 2) where +1 is the sign nibble
And PIC S9(n) COMP maps to binary with correct byte length (1-4 digits=2, 5-9=4, 10-18=8 bytes)
And FILLER fields are included with generated names
And REDEFINES fields are tracked (redefined field noted, not duplicating positions)
And OCCURS clauses expand to repeated field groups (single-level only; nested OCCURS raises ValueError with line context)
And level 88 condition names are skipped (not data fields)
```

<task type="auto">
  <name>Task 2: Implement COBOL copybook parser</name>
  <files>backend/app/infrastructure/parsers/__init__.py, backend/app/infrastructure/parsers/copybook_parser.py</files>
  <action>
    1. Create backend/app/infrastructure/parsers/__init__.py (empty, package marker)

    2. Create copybook_parser.py with class CopybookParser:

       Method: parse(copybook_text: str, name: str = "copybook", default_format: FileFormat = FileFormat.VSAM_FIXED, default_encoding: EncodingType = EncodingType.EBCDIC_CP037) -> FileSchemaDefinition

       Parsing logic:
       a0. Input guard: reject if len(copybook_text) > 1_048_576 (1MB) or line count > 10_000. Raise ValueError("Copybook exceeds size limit"). <!-- audit-added -->

       a. Pre-process: strip sequence numbers (cols 1-6), strip comment lines (col 7 = '*'), join continuation lines (col 7 = '-'), normalize whitespace

       b. Split into entries by level number boundaries (01-49, 77, 88)

       c. For each entry, extract:
          - Level number (01-49, 77)
          - Field name (or FILLER)
          - PIC clause (if present)
          - COMP / COMP-3 / BINARY usage clause
          - REDEFINES target
          - OCCURS count
          - VALUE clause (skip, not relevant)

       d. Skip level 88 entries (condition names, not data)

       e. Skip group-level entries (have subordinate fields but no PIC) — they don't occupy their own storage

       f. PIC clause parsing:
          - X(n) or X repeated n times → alphanumeric, length=n, byte_length=n
          - 9(n) or 9 repeated n times → numeric display, length=n, byte_length=n
          - S9(n) → signed numeric, add sign byte consideration
          - 9(n)V9(m) → decimal, length=n+m, decimal_places=m, byte_length=n+m (display)
          - With COMP-3: byte_length = ceil((total_digits + 1) / 2) where total_digits includes all 9s (before and after V), +1 is sign nibble. Example: S9(7)V99 = 9 digits + 1 sign = 10 nibbles = 5 bytes. Unsigned 9(5) = 5 digits + 1 sign = 6 nibbles = 3 bytes. <!-- audit: clarified formula -->
          - With COMP: byte_length based on digit count: 1-4 digits=2 bytes, 5-9=4 bytes, 10-18=8 bytes

       g. Position computation:
          - Track running byte offset starting at 0
          - REDEFINES: reuse the start_position of the redefined field, do NOT advance offset
          - OCCURS: multiply byte_length by occurs count for position advancement; expand into N copies named {field_name}_{1..N}. If a nested OCCURS is detected (OCCURS inside an already-expanding group), raise ValueError with line number: "Nested OCCURS not supported at line {N}". <!-- audit-added -->
          - FILLER: assign name "FILLER_{seq}" with incrementing counter

       h. Build FileSchemaDefinition:
          - Set fields, format=default_format, encoding=default_encoding
          - Compute record_length from final byte offset
          - Store original copybook name in metadata

       Method: parse_file(file_path: Path, **kwargs) -> FileSchemaDefinition
       - Read file as text, delegate to parse()

       Error handling:
       - Raise ValueError with line number and offending clause text for unparseable PIC clauses (e.g., "Invalid PIC clause 'PIC Z(3)9' at line 14") <!-- audit: structured errors with line context -->
       - Log warnings (structlog) for skipped entries (groups, level 88s)
       - Collect parse warnings in metadata["warnings"] list, each entry including line number

    Avoid: external COBOL parsing libraries in this implementation — this is the custom parser.
    Avoid: modifying any existing files outside the parsers package.
  </action>

from app.infrastructure.parsers.copybook_parser import CopybookParser

           05  CUST-NAME        PIC X(30).
           05  CUST-SSN         PIC 9(9).
           05  CUST-BALANCE     PIC S9(7)V99 COMP-3.
           05  FILLER           PIC X(5).
           05  CUST-TYPE        PIC X(2).
''')

assert result.file_format.value == 'vsam_fixed'
