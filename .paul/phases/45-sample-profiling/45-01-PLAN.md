## AC-2: VSAM parser reverses 44-02's wire format
```gherkin
Given a VSAM_FIXED or VSAM_VARIABLE file from VSAMWriter
When parse_vsam(path, schema) is called
Then EBCDIC text fields decode back to their input strings
And COMP-3 fields decode back to their original signed scaled integers / decimals
And COMP fields decode back via int.from_bytes(..., big, signed)
And display-signed overpunch fields decode back to signed integers
And VSAM_VARIABLE files honor the 4-byte RDW prefix per record.
```

## AC-3: DistributionProfiler produces per-column profiles
```gherkin
Given a DataFrame with mixed numeric / categorical / string columns
When DistributionProfiler.profile_dataframe(df) runs
Then the returned dict maps each column name to a ColumnProfile with:
  - dtype ("numeric" | "categorical" | "string")
  - null_rate (float between 0 and 1)
  - For numeric: min, max, mean, std (None if all nulls)
  - For categorical: a frequencies dict (value → count) if cardinality < 50
  - For string: a regex pattern hint if values match a single simple pattern
```

## AC-4: FakerEngine honors column profiles when provided
```gherkin
Given schema_metadata = {"column_profiles": {"col_a": ColumnProfile(...)}}
When FakerEngine.generate(config, schema_metadata) runs
Then for numeric columns: generated values fall within [min, max]
And for categorical columns: generated values are drawn from the learned set
And null_rate is honored within a 10% tolerance for sample sizes >= 100
And when no profile is present, behavior is unchanged from Phase 1.
```

<task type="auto">
  <name>Task 1: Sample file parsers</name>
  <files>backend/app/infrastructure/parsers/sample_file_parser.py</files>
  <action>
    Create `sample_file_parser.py` with module-level functions (no class needed):

    Imports: `pandas as pd`, `pathlib.Path`, `pyarrow.parquet as pq`, `pyarrow.orc as orc`,
    plus the writers' helpers — `ebcdic_codec`, `cobol_encoding`.

    `parse_csv(path: Path, schema: FileSchemaDefinition, **csv_opts) -> pd.DataFrame`:
      - Use `pd.read_csv(path)` with default dtype inference.
      - Validate that the columns match the schema's non-filler field names.

    `parse_fixed_width(path: Path, schema: FileSchemaDefinition) -> pd.DataFrame`:
      - Build colspecs from `(field.start_position, field.start_position + field.byte_length)` for non-filler, non-redefines fields.
      - Use `pd.read_fwf(path, colspecs=colspecs, names=names, dtype=str)`.
      - Coerce types from schema (numeric → int, decimal → float with implied-decimal scaling).

    `parse_vsam(path: Path, schema: FileSchemaDefinition) -> pd.DataFrame`:
      - Determine variable-length from `schema.file_format == "vsam_variable"`.
      - record_length = schema.compute_record_length(); RDW = 4 if variable.
      - Read the file in chunks of (RDW + record_length).
      - For each record:
        - If variable: parse RDW prefix as big-endian uint16 minus 4 to verify; skip the 4 bytes.
        - For each non-redefines, non-filler field:
          - Slice bytes from start_position.
          - Decode based on data_type + comp_type:
            - `alphanumeric` → `bytes.decode(stdlib_codec).rstrip()`
            - `numeric/decimal` with `comp_type == "comp_3"` → unpack nibbles, scale by 10**decimal_places
            - `numeric/decimal` with `comp_type == "comp"` → int.from_bytes(..., "big", signed)
            - signed display → reverse overpunch (last byte → digit + sign), join with leading digits
            - unsigned display → bytes.decode(codec) as int / float
      - Return DataFrame keyed by field names.

    `parse_columnar(path: Path, schema: FileSchemaDefinition) -> pd.DataFrame`:
      - if Parquet: `pq.read_table(path).to_pandas()`
      - if ORC: `orc.read_table(path).to_pandas()`
      - else: raise ValueError.
      - For decimal columns, convert Decimal → float for consumer convenience.

    `parse(path, schema)` — top-level dispatcher by `schema.file_format`.
  </action>

  <files>backend/app/infrastructure/engine/distribution_profiler.py</files>
  <action>
    Create `distribution_profiler.py`:

    `@dataclass class ColumnProfile`:
      - column_name: str
      - dtype: Literal["numeric", "categorical", "string"]
      - null_rate: float
      - min: float | None
      - max: float | None
      - mean: float | None
      - std: float | None
      - cardinality: int
      - frequencies: dict[str, int] | None  # for categorical
      - pattern_hint: str | None  # regex literal for string types
      - sample_values: list  # first 5 non-null values

    Class `DistributionProfiler`:
      `profile_dataframe(self, df: pd.DataFrame) -> dict[str, ColumnProfile]`:
        - For each column, dispatch on dtype:
          - numeric → compute min/max/mean/std, set dtype="numeric"
          - object with cardinality < 50 → dtype="categorical", build frequencies
          - object otherwise → dtype="string", try simple pattern detection
        - Pattern detection: build a regex from the first ~20 non-null values:
          - replace digit runs with `\d+`
          - replace letter runs with `[A-Za-z]+`
          - if all values match the same simplified pattern, use it as the hint
        - null_rate = `df[col].isna().mean()`.

    All pure-Python + pandas + numpy; no new deps.
  </action>

    Extend `FakerEngine._generate_table` to accept and honor
    `schema_metadata["column_profiles"]`:

    1. Add `column_profiles` parameter to `_generate_table` (default None) and
       thread it through from `generate()`.
    2. In the per-column loop, if a profile exists for `col_name`:
       - dtype == "numeric": sample a value from a uniform [min, max] (use the
         profile's min/max). Respect null_rate via random draw.
       - dtype == "categorical": sample from `frequencies` weighted by counts.
       - dtype == "string" with `pattern_hint`: use `Faker.bothify` or similar
         to generate a matching pattern (fall back to stock generation if the
         pattern can't be honored).
       - null_rate handling: with probability `null_rate`, set value to None
         when the column is nullable.
    3. If no profile is present, fall through to existing behavior — backward-
       compatible.

    Keep existing PII handling intact: PII type wins over profile (PII flag
    overrides — don't leak real-looking values through profile sampling).
