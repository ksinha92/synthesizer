<objective>
## Goal
Replace the JSON DAG editor with a ReactFlow drag-and-drop visual canvas — 5 custom node types with icons and status indicators, node palette, edge connections with validation, per-node config panel, and dual-mode toggle (visual ↔ JSON).

## Purpose
This is the headline UX feature from the competitor analysis. Visual workflow building is what none of the competitors (Delphix, UX-refactor) offer. It transforms DataWrangler from a tool collection into an integrated platform.

## Output
- ReactFlow canvas with custom node components
- Node palette (drag to add)
- Edge validation (type-compatible connections only)
- Per-node config panel (bottom drawer)
- Dual-mode: visual ↔ JSON toggle
- Workflow detail page with canvas
</objective>

<context>
## Prior Work
- Phase 15: Workflow backend (DAG validation, execution engine, CRUD API)
- Phase 16: JSON DAG editor (being replaced by visual canvas)
</context>

<acceptance_criteria>

## AC-1: ReactFlow canvas renders workflow DAG with custom nodes
```gherkin
Given a workflow with a saved DAG definition
When the workflow detail page loads
Then ReactFlow renders nodes at their saved positions
And each node type has a distinct color + icon (Discover=blue, Mask=orange, Generate=green, Subset=purple, Export=gray)
And edges connect nodes with animated arrows
```

## AC-2: Drag-and-drop from node palette creates new nodes
```gherkin
Given the workflow editor is open
When a user drags a node type from the palette onto the canvas
Then a new node is created at the drop position
And the DAG definition updates to include the new node
```

## AC-3: Dual-mode toggle switches between visual canvas and JSON editor
```gherkin
Given the workflow editor
When the user toggles between Visual and Code mode
Then changes sync bidirectionally (canvas changes reflect in JSON and vice versa)
```
