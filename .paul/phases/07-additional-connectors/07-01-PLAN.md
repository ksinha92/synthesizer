<task type="auto">
  <name>Task 2: Implement MongoDB connector via motor with document sampling</name>
  <files>
    backend/app/infrastructure/connectors/nosql/__init__.py,

  <action>
    1. Add dependency: motor>=3.6.0 (async MongoDB driver)

    2. Create MongoDBConnector(BaseConnector):
       - Uses motor.motor_asyncio.AsyncIOMotorClient
       - test_connection(): client.admin.command("ping") with 5s timeout
       - get_schemas(): list_database_names() — filter out admin, local, config
       - get_tables(schema): list_collection_names() on database, with estimated_document_count() for each
       - get_columns(schema, collection): SCHEMA INFERENCE via document sampling:
         - Sample 100 documents from collection (aggregate $sample or find().limit(100))
         - For each field across all samples: track Python type occurrences
         - Infer column metadata:
           - name: field path (nested fields as dot notation: "address.city")
           - data_type: most common Python type → SQL-like type (str→varchar, int→integer, float→double, bool→boolean, datetime→timestamp, list→jsonb, dict→jsonb, ObjectId→uuid)
           - is_nullable: True if field missing in any sampled document
           - is_primary_key: True only for "_id" field
         - Flatten nested documents to max depth 2 (avoid infinite recursion)
       - get_sample_data(schema, collection, limit): find().limit(limit), serialize ObjectId to string, flatten nested to max depth 2
       - close(): close motor client
       - All methods: 30-second asyncio.timeout

    MongoDB has no information_schema — schema is inferred from data. This is fundamentally different from SQL connectors and is the correct approach.

    Memory safety for document sampling: <!-- audit-added -->
    - Skip documents larger than 1MB (len(bson.encode(doc)) > 1_000_000)
    - Cap total sampling memory at 50MB — stop sampling if cumulative size exceeds limit
    - Log warning when documents skipped due to size

    Avoid: Blocking the event loop — motor is async, use it properly.
    Avoid: Infinite recursion on deeply nested documents — cap at depth 2.
  </action>
  <verify>
    - `python -c "from app.infrastructure.connectors.nosql.mongodb import MongoDBConnector"` succeeds
    - get_columns returns inferred schema from document sampling
    - Nested fields flattened with dot notation (max depth 2)
    - ObjectId serialized to string in sample data
    - All methods have asyncio.timeout(30)
  </verify>
  <done>AC-2 satisfied: MongoDB connector infers schema from document sampling with type mapping.</done>
