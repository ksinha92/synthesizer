    1. Create backend/app/infrastructure/connectors/base.py:
       - BaseConnector ABC with async methods:
         - test_connection() -> bool
         - get_schemas() -> list[dict] (name)
         - get_tables(schema: str) -> list[dict] (name, row_count, size_bytes)
         - get_columns(schema: str, table: str) -> list[dict] (name, data_type, is_nullable, is_primary_key, is_foreign_key, fk_references)
         - get_sample_data(schema: str, table: str, limit: int = 100) -> list[dict]
         - close() -> None
       - __init__ takes connection config dict (host, port, database_name, credentials, extra_params)

    2. Create backend/app/infrastructure/connectors/registry.py:
       - ConnectorRegistry class:
         - _connectors: dict[ConnectorType, type[BaseConnector]] — class registry
         - register(connector_type, connector_class) — registers a connector class
         - get_connector(connector_type, config) -> BaseConnector — instantiates and returns
         - Raises NotFoundError for unregistered types
       - Auto-register PostgreSQLConnector on import

    3. Create backend/app/infrastructure/connectors/sql/postgresql.py:
       - PostgreSQLConnector(BaseConnector):
         - Uses asyncpg for connection (NOT SQLAlchemy — raw async driver for introspection)
         - test_connection(): try asyncpg.connect() with 5s timeout, return True/False
         - get_schemas(): SELECT schema_name FROM information_schema.schemata WHERE schema_name NOT IN ('pg_catalog', 'information_schema')
         - get_tables(schema): SELECT table_name, pg_total_relation_size, n_live_tup from pg_stat_user_tables filtered by schemaname
         - get_columns(schema, table): SELECT from information_schema.columns + constraint info for PKs/FKs
         - get_sample_data(schema, table, limit): <!-- audit-added: explicit SQL injection prevention -->
           1. FIRST query information_schema.tables to get all valid (schema_name, table_name) pairs
           2. Check that the user-supplied (schema, table) exists in that result set — reject with ValueError if not
           3. ONLY THEN construct the query using the validated names: f'SELECT * FROM "{validated_schema}"."{validated_table}" LIMIT $1' with limit as parameter
           4. This two-step validation is the ONLY safe pattern for dynamic table names in SQL
         - All introspection methods (get_schemas, get_tables, get_columns, get_sample_data) must have a 30-second asyncio.timeout wrapper to prevent hanging on slow databases <!-- audit-added: timeout protection -->
         - close(): close asyncpg connection pool

    Avoid: Using SQLAlchemy for introspection — asyncpg is faster and gives raw access to information_schema.
    Avoid: String interpolation for SQL — use parameterized queries everywhere. For schema/table names (which can't be parameterized), validate against information_schema before using.
  </action>
